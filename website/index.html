Open-source prompt infrastructure

Ship AI prompts with the same rigor as application code.

PromptOpsKit is a developer-first toolkit and CLI for authoring prompts in Markdown, validating schema and variables before runtime, and rendering provider-specific request bodies without locking you into a transport stack.

Install from npm Read the quick start 
npm install promptopskit
npx promptopskit init ./prompts
promptopskit validate ./prompts --strict

Why teams adopt PromptOpsKit

Predictable prompt changes

Store prompts in markdown with front matter so every change is diffable, reviewable, and auditable.

Portable provider output

Generate request bodies for OpenAI, Anthropic, Gemini, and OpenRouter while keeping network logic in your app.

Safer releases

Catch invalid schema, unresolved variables, and malformed composition before your production calls fail.

Prompt management features for engineering teams

Authoring format engineers already trust

  • Markdown files with YAML front matter
  • H1 sections for system instructions and prompt template
  • {{ variable }} interpolation and strict checks

Composition and overrides without duplication

  • includes for shared policy, tone, and safety blocks
  • Environment and tier-specific overrides
  • Deterministic precedence: base → env → tier → runtime

CLI for local and CI pipelines

  • init, validate, render, inspect, compile, and skill
  • Pre-compile prompts to JSON/ESM artifacts
  • Use in pre-merge checks and release workflows

No transport lock-in

  • Adapters return request body only
  • You keep control of auth, retries, headers, and observability
  • Integrates with existing HTTP and infra standards

PromptOpsKit quick start

1) Install and scaffold

npm install promptopskit
npx promptopskit init ./prompts

2) Render for your target provider

import { createPromptOpsKit } from 'promptopskit';

const kit = createPromptOpsKit({ sourceDir: './prompts' });
const result = await kit.renderPrompt({
  path: 'support/reply',
  provider: 'openai',
  variables: { user_message: 'How do I reset my password?' }
});

Frequently asked questions

Is PromptOpsKit only for one model provider?

No. It supports OpenAI, Anthropic, Gemini, and OpenRouter adapters out of the box.

Does PromptOpsKit make HTTP requests?

No. It returns request-body payloads so your app controls auth, transport, retries, and headers.

Can we validate prompts in CI before deploy?

Yes. Use the CLI validate and compile commands in your CI pipeline to catch issues before release.

Is PromptOpsKit open source?

Yes. The project is MIT-licensed and maintained in a public GitHub repository.

Open source and production-ready defaults

PromptOpsKit is MIT-licensed and designed for teams that need testable prompt operations. Use source prompts in development and pre-compiled artifacts in production for speed and reliability.
